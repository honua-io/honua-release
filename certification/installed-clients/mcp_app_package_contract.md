# Authored map-to-app draft certification

Refs honua-release#716 (actual installed-candidate execution remains) and
geospatial-mcp#122 (thin producer adoption remains). This covers eight original
catalog rows: create_app_package, App package resources/read, validate_package
and preview_package through the official SDK and Inspector. It changes no
catalog, platform pin, candidate binding or qualification denominator.

The release-owned producer runs immediately after each named client's existing
execute_plan journey. Its independent oracle rejudges that journey's complete
raw observations, including the actual generated geometric artifact and durable
job/result records. It then invokes canonical create_map_package against the
independently bootstrapped published-layer fixture and validates the actual map
contents, selectors, extent and identity. Only those observed map/artifact IDs
become the app's mapPackageId and nonempty boundArtifactIds. Runtime configuration
contains nonempty authored values and the actual buffer artifact reference.

Creation must preserve all composition selectors, runtime configuration, bound
artifact references and closed sharing (private, non-embeddable, unreviewed).
Invalid runtime configuration and duplicate artifact bindings must produce typed
validation refusals. The package contents come from actual create output. A new
session then reads the exact app resource as draft lifecycle metadata with no
deployment edges; unknown and anonymous resource reads must be typed refusals.

The canonical generic review adapter checks declared requirements. It does not
execute or resolve the opaque app payload. Both review tools receive the actual
created package, real map/artifact references declared as resolved requirements,
and explicit approval controls. A ready case and an unresolved publish approval
case must yield the corresponding actionable decisions. Validate returns no
preview. Preview returns the exact read-only generic plan with the real input
references; it is not an image render or application execution.

Each invocation retains actual initialized/invoked raw request/response bytes,
hashes, named installed-client launch/result identity and a distinct session.
Authenticated initialize and invocation must forward the expected private
credential; anonymous tool and resource refusals must have actual wire proof.
Public Inspector local roster refusal cannot substitute for tools/call wire.
Candidate inspection brackets the journey and must match the existing execution
journey's current runtime. Missing or changed prerequisites remain NONPASS.

The default app draft store is age-bounded in-memory scratch. Fresh-session
readback establishes neither restart durability nor cross-replica visibility.
The app journey runs after the execution prerequisite's restart and never
restarts the newly created app. It does not prove publishing, deployment, bundle
generation, application runtime behavior or the separate immutable deployment
lifecycle. Offline controlled HTTP/client vectors are source tests only; they
grant no installed-client or candidate credit. Existing global cancellation,
pagination, authority, tier and cohort gates still apply at fragment admission.
