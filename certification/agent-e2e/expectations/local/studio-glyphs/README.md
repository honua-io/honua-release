These Open Sans Regular glyph ranges are fixed inputs for the runner's independent
MapLibre renderer. They are from the OpenMapTiles fonts repository, `gh-pages`
commit `025ff2b2f84cc0fdf11f7b1d74b3a784595fe7a4`. The Open Sans font is
licensed under Apache License 2.0; its license text is included here. The
renderer serves these bytes only from its own loopback origin and verifies their
SHA-256 digests before use.
