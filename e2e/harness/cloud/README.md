The cloud seam uses an installed toolchain in `e2e-cloud-aws.yml`, rather than a published harness image. MCP, Studio and GP already use curl, jq and Python. The only additional client is Playwright 1.61.1 with its matching Chromium build. The demo source is the same reviewed honua-site SHA as the local harness. Installing this in the existing job avoids a separate image build, registry artifact and publishing workflow.

`e2e/runner/cloud.py` receives the live cell endpoint and target, publishes the local harness's SQL fixtures and service policies, then runs `e2e/drivers/{mcp,studio,gp,demos}/run.sh`. Terraform cells read their existing database connection from their own applied state in memory; EKS applies the same SQL inside its own PostGIS pod. Nothing changes repository credentials, secrets or variables. Drivers receive the per-run application key, without AWS credentials or dispatch tokens. Database passwords stay out of subprocess arguments and published evidence.

Each driver's detailed rows go through the local `assemble_report` into a cell-scoped `extended/gate-report.json`. The four summarized verdicts, including those detailed rows, are also retained in `gate-report-cloud.json`. A missing/duplicate verdict, seed failure, crash or real driver failure is FAIL. A genuine unmet precondition remains BLOCKED and `require_real` promotes it to a cell FAIL. Canonical parity comparison is unchanged. Drivers run before the imported journey and before the existing teardown/reaper.

Remaining `top-demo` precondition (honua-release#450): the reviewed site's CSP permits loopback and HTTPS honua.io backend origins. A default AWS ALB/API Gateway hostname cannot satisfy that policy. `check-backend.mjs` executes the pinned site's own bootstrap and the demo driver reports BLOCKED when it excludes the cell origin. The cell needs a policy-admitted HTTPS endpoint and must permit the local demo origin through CORS; the harness never widens CSP or fabricates CORS responses. The three HTTP drivers have no analogous hostname restriction.
