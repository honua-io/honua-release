## What counts as core

`certification/check_build_test.py` keeps the latest attempt of each check name for one
app and one Actions workflow. A later success replaces an older failure of that same
lane. A later failure replaces an older success. Actions suites that have no recorded
workflow id stay independent, so a missing metadata read cannot hide a red.

A latest attempt is core when its name is not in the env-gated, roll-up, security, or
governance lists, and it is not advisory. Advisory is an exact job name, or an exact
workflow path that enrichment stored on the check-run. A workflow exclusion does not
apply when that path is absent. If every check is excluded, the component is blocked.
It does not pass.
