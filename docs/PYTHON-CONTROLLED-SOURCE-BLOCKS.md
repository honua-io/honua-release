# Controlled Python source blocks

This runner is a prerequisite for release issue #721. It executes the three
immutable SDK README/INSTALL source blocks, including their twelve ordered pip
calls and the development block's original lint, type, test and compatibility
commands. It does not admit installed source packages to the executable-docs
audit, establish published-wheel identity, or qualify a release candidate.

The selected inputs distinguish protected producer implementation `f36e702e`
from subject checkout `5a793520`. The original producer artifact, exact image
index/amd64 manifest/config chain, runtime policy, original pip, packaging tool,
document bytes and command hashes remain fixed. The original full outer and
inner verifiers run without path, marker or command normalization. A small
native control first invokes the real producer runtime/action/build APIs to
check the consumer's paths before the large artifact is fetched.

The explicitly derived recipe performs a real clone from authenticated immutable
Git input at each original clone request, checks out the selected commit, checks
every tracked blob and mode, and transposes those working-tree bytes into the
ordinary reader destination. The separately authenticated Git metadata remains
read-only in both containers. The receipt records the original request, actual
commands, private staging, transposition and unchanged metadata. This is an
immutable-source substitution, not equivalence to a mutable network clone.

Each complete original source block runs in one shell in a separate reader PID
namespace. The private controller retains source/closure/file-census state; it
exposes only exact, ordered install/clone requests. The reader has only its own
source and environment binds, read-only Git metadata and bridge, and private
home/state. It cannot write controller code, home, warehouse, request or proof
state. The exact source blocks contain all pip requests before arbitrary
development commands; other phase layouts refuse. Final interpreter audit runs
only after the reader and all its actual children have terminated. No observer
timeout stops a container to obtain a successful postcheck; an interrupted live
container retains its identity and cleanup-pending record.

The `Python controlled source blocks` workflow accepts only protected-trunk
manual dispatch. The existing cross-repository reader token reaches one fixed
artifact-fetch step. Controller and reader containers receive no token. The
workflow retains original command/stream receipts and refusal records, while
the original input artifact stays independently identified by its immutable
producer/run/job/artifact digest.

Remaining work includes source-cited typed context wiring in `run.py`, terminal
private-tmp/home/source and invoked-interpreter census, acceptance of only the
fully proved source environment, and execution of every original document block
against the current candidate. Published install/API examples retain the
unchanged default package/origin audit. No proof from this runner changes the
35-document denominator or closes the full SDK documentation obligations.
