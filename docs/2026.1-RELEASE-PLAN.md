## 2026-10-25 re-tier

The [2026-10-25 founder re-tier](https://github.com/honua-io/honua-release/issues/376#issuecomment-6407009748) amends the plan below without editing the canonical item: the GA topology is Docker
Compose on-prem plus AWS ECS, and the two `aws-ecs` cells are the only required cloud cells. AWS Lambda,
EKS, Helm and the GP catalog are Preview. Architecture is x86_64 only. The AI gates (full agent gate,
genuine-model canary) are out of RC admission. Where a line below names four GA cells, Lambda as GA or
a required catalog-GP denominator, this amendment governs.

## Milestones

The canonical plan owns the assisted-pilot-first amendment (2026-10-16), weekly outcome board and changes to these dates. Date windows are explicit decision checkpoints, not guarantees.

| Milestone | Target | Bar |
|---|---|---|
| M1: assisted pilot and developer preview | before RC checkpoint; prior October 13 target missed | ECS Redis-on install → import → actual GP → AI 2D map save/reopen → proposal → separate approval → final URL → protected configuration change; three fresh starts, recorded assistance/clarification and at most one visible retry. The install manifest stays `pre-cut-rehearsal`. |
| M2: first certified lock `2026.1-rc.3` | 2026-10-27 to 2026-11-03 | First all-green nightly strict train on trunk head mints a signed lock; genuine-model journey passes on all four GA cells against a certified lock. Nightlies use the deterministic driver on all four cells plus one genuine-model cell (ECS, Redis off). |
| M3: GA `honua-2026.1.0` | 2026-11-17 to 2026-12-01 | Select promotion candidate rc.N; gather genuine-model evidence on all four cells, signed rc.3 → rc.N → rc.3 update/rollback proof, Esri and CITE bound to the lock; burn 48 hours with seven lock-bound canaries while trunk moves; pass GA docs gates and move channels through promotion. |

If M2 is not met by 2026-11-03, the operator rules on scope before work continues; dates do not slide
silently. R18–R21 establish continuous certification: no source freeze or hand re-pin. The freeze on adding required gates before rc.3 remains. New commits and newer
locks do not reset a selected lock's burn; any failure of that lock after minting ends it. Promotion
is allowed from hour 48 until any evidence passes its freshness bound, capped per class by the checker,
without a 72-hour deadline or later strict-train requirement. Every consumed evidence class is declared nightly or qualifying and bound to the lock.

GA cells are All-ECS × {Redis off, Redis on}. Lambda + Batch, mixed ECS + Batch and EKS run as
informational Preview cells (2026-10-25 re-tier). Each required journey cell passes within two recorded attempts, with
failures attributed to model or infrastructure. See [BURN-IN-PROMOTION.md](BURN-IN-PROMOTION.md) for the
readiness contract and remaining workflow integration.

Redis-on is recommended for full workflows; Redis-off is limited serving with typed refusals, never proof of GP execution. The self-hosted Studio is a usable 2D Preview alongside full agent flows. Supported-service and two existing JavaScript app migrations may complete with documented assistance/manual fixes. Silent wrong results, data loss, unauthorized actions and false success remain unacceptable.

The October 16 amendment explicitly supersedes EKS decisions 12/18. It preserves correctness/security floors, the required catalog-GP denominator, immutable-image resolver rules and the gate freeze before first rc.3. Campaign #619 does not gate RC; GP developer experience/parity #613–#617 remains 2026.2. The external active Windows certification lane retains desktop-scripting certification ownership; await its receipts.

Preview qualification is informational; failed or unknown cleanup, leaked run-owned resources and run cost overruns remain fatal. EKS teardown always executes and its independent workflow/aggregation checks retain the pre-amendment safety bar.
