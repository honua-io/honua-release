# 2026.1 release plan

The canonical 2026.1 release plan is the Specifica item
[`2026-1-release-plan-ai-cloud-to-maps`](https://github.com/honua-io/agent-delivery-spec/tree/trunk/.specifica/2026-1-release-plan-ai-cloud-to-maps/),
projected to [honua-release#376](https://github.com/honua-io/honua-release/issues/376). Edit it there and resync;
don't copy its content into this repository.

It supersedes the 2026-09-09 first-cut epic ([honua-release#120](https://github.com/honua-io/honua-release/issues/120)).
It does not replace the gate architecture in [RELEASE-ENGINEERING-PLAN.md](RELEASE-ENGINEERING-PLAN.md) or the cut runbook
in [RELEASE-CUT-CHECKLIST.md](RELEASE-CUT-CHECKLIST.md). The [decision record](2026.1-release-decision-record.md) is
generated: it is refreshed with `tools/release_decision_record.py` once the plan's rulings are recorded, and never
hand-edited.

## Milestones

| Milestone | Bar |
|---|---|
| M1: developer preview | A recorded genuine-model run on real AWS: install → publish a layer and 2D map → roll back → tear down. `customer-install-manifest.json` stays `pre-cut-rehearsal`; nothing claims qualification. |
| M2: `2026.1-rc.3` | The first real cut. A strict freeze train is green, including the promise journey on the four GA cells. |
| M3: `honua-2026.1.0` | rc.4 is promoted with the rc.3 → rc.4 → rc.3 update and rollback proof, three strict trains, seven canaries, the burn window and the GA docs gates. |

GA cells are {All-ECS, Lambda + Batch} × {Redis off, Redis on}. Mixed ECS + Batch and EKS run as informational
Preview cells.
